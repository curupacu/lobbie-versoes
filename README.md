# Lobbie

Sua biblioteca de jogos fora da Steam, com amigos, horas jogadas e chat.

**Baixar:** [Lobbie-instalador.exe](https://github.com/curupacu/lobbie-versoes/raw/main/Lobbie-instalador.exe) (versão 0.4.0, Windows 10/11)

Depois de instalado, o Lobbie se atualiza sozinho.

O Windows pode mostrar "O Windows protegeu o computador" porque o instalador não é assinado por uma empresa: clique em **Mais informações → Executar assim mesmo**.

Novidades da 0.4.0: Conquistas do Lobbie (por jogo e da conta, com aviso e feed), Procurar jogos no PC (Epic, GOG, pastas e ROMs) e RetroAchievements.
